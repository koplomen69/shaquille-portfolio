# Shaquille Rayhannizam Wibisono — Portfolio

Interactive Three.js portfolio matching the cybernetic systems design system, built from CV and certification records.

## Stack

- Vite
- Three.js (particle field, wireframe nodes, reactive camera)
- Vanilla JS + CSS design tokens from `stitch_professional_cv_portfolio_website/DESIGN.md`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Content

Edit `src/data.js` for profile, experience, projects, certifications, education, and HKI.
CV download is served from `public/CV no photo.pdf`.
