## Brand & Style

This design system expresses the intersection of enterprise enterprise-resource architecture (SAP), cutting-edge artificial intelligence, and applied hardware/IoT engineering. It is engineered specifically for technical directors, enterprise recruiters, venture researchers, and academic collaborators seeking rigorous full-stack and systems competence.

The aesthetic fuses **Precision Dark Minimalism** with **Cybernetic Glassmorphism**:
- Deep obsidian and charcoal basalt surfaces establish an authoritative, distraction-free environment.
- Electric emerald (`#10B981`) and radiant cyan (`#06B6D4`) neon accents evoke sensor telemetry, terminal execution, and neural network graphs.
- High-precision monospaced accents ground the presentation in technical credibility, balancing modern corporate executive gravitas with R&D laboratory innovation.

## Colors

The palette establishes high chromatic discipline across dense data and research narratives:

- **Primary (`#10B981` - Emerald Matrix):** Represents active operational logic, live deployment, validated certifications, and core interactive states.
- **Secondary (`#06B6D4` - Cybernetic Cyan):** Drives telemetry readouts, IoT sensory nodes, metric indicators, and tertiary hover interactions.
- **Tertiary (`#3B82F6` - Enterprise Azure):** Reflects SAP systems architecture, formal institutional achievements, and Microsoft cloud verifications.
- **Neutrals:**
  - Base Canvas: Deep Obsidian (`#090D12`)
  - Elevated Container: Slate Basalt (`#0F172A` at 65% opacity with backdrop blur)
  - Surface Highlight: Frosted Edge (`rgba(255, 255, 255, 0.08)`)
  - High Contrast Typography: Crisp Ice (`#F8FAFC`)
  - Subdued Metadata: Cool Graphite (`#94A3B8`)

## Typography

The type scale balances executive legibility with technical precision:
- **Headlines (`Plus Jakarta Sans`):** Contemporary geometry with tight tracking provides an authoritative, modern tech presence across hero intros and section headers.
- **Body Text (`Inter`):** Neutral, hyper-legible neo-grotesque font engineered for dense technical abstracts, project case studies, and research publications.
- **Technical & Metric Roles (`JetBrains Mono`):** Applied exclusively to metadata, scores (e.g. `GPA: 3.63/4.00`, exam scores `86/100`), system parameters, dates, and technology badges (e.g. `ESP32`, `Gemma 12B`, `SAP BC400`).

## Layout & Spacing

A 12-column responsive grid structures data-rich showcases:
- **Desktop (>= 1200px):** 12 columns with `1.5rem` gutters and `3rem` outer margins. Content containers max out at `1280px` centered width.
- **Tablet (768px - 1199px):** 8 columns with `1.25rem` gutters and `2rem` margins.
- **Mobile (< 768px):** 4 columns with `1rem` gutters and `1.25rem` outer canvas padding.

Spacing is governed by an 8pt rhythm. Dense telemetry grids and credential details leverage `space-xs` and `space-sm` for compact organization, while case study modules and section dividers breathe via `space-xl`.

## Elevation & Depth

Visual hierarchy uses a refined dark-mode glass stack rather than heavy drop shadows:

1. **Base Layer (`Level 0`):** Solid `#090D12` background accented by subtle ambient radial gradients in emerald (`rgba(16, 185, 129, 0.05)`) and cyan (`rgba(6, 182, 212, 0.04)`) anchored to corners and interactive nodes.
2. **Glass Container (`Level 1`):** Background `rgba(15, 23, 42, 0.72)` paired with `backdrop-filter: blur(16px)` and a crisp outer stroke of `1px solid rgba(255, 255, 255, 0.08)`.
3. **Interactive & Hover State (`Level 2`):** Background transitions to `rgba(30, 41, 59, 0.85)` with a subtle neon edge glow `box-shadow: 0 0 20px -4px rgba(16, 185, 129, 0.25)` and top-border highlight `rgba(255, 255, 255, 0.16)`.
4. **Modal / Full Credential Inspect (`Level 3`):** High-opacity obsidian backdrop `rgba(9, 13, 18, 0.92)` blur `24px` with a defined border accent `1px solid rgba(6, 182, 212, 0.3)`.

## Shapes

The design uses balanced rounded geometry (`Level 2`, base radius `0.5rem` / `8px`):
- Standard cards, interactive code blocks, and project containers utilize `rounded-lg` (`1rem` / `16px`).
- Minor badges, inputs, buttons, and system chips use base radius `0.5rem` (`8px`).
- Status indicators and avatar nodes use circular boundaries (`9999px`).
- Borders remain ultra-thin (`1px`) with crisp geometric containment, eliminating soft skeuomorphic bevels in favor of sharp architectural lines.

## Components

### Buttons & CTAs
- **Primary Action (Direct Contact / Run Demo):** Emerald background `#10B981` with dark ink `#090D12` typography in font weight 600. Glowing focus ring in cyan (`#06B6D4`).
- **Secondary Action (View Verification / PDF Resume):** Transparent dark slate with a `1px` border of `rgba(255, 255, 255, 0.14)`. Hover transitions border to emerald and text to pure white.
- **Icon Action (GitHub, LinkedIn, Terminal):** Ghost button with subtle `rgba(255, 255, 255, 0.05)` surface, elevating with a faint emerald backlight on hover.

### Technology & Research Badges (Chips)
- Structured using `label_font` (`JetBrains Mono`).
- Background: `rgba(16, 185, 129, 0.08)` for AI/IoT tags; `rgba(6, 182, 212, 0.08)` for ERP/SAP tags.
- Border: `1px solid rgba(16, 185, 129, 0.25)` or cyan equivalent.
- Text: Crisp neon-tinted monospace type.

### Credential & Verification Showcase Cards
- Dedicated layout pattern for formal credentials (e.g., Microsoft Security Fundamentals 98-367, Azure AI-900, Ternakpark R&D Certification, SAP Speaker roles).
- Top header featuring an institutional logo slot alongside a status badge (e.g., `SCORE: 86/100 • PASSED` or `VERIFIED ON-CHAIN/PORTAL`).
- Content area utilizing two-column metadata lists with monospace values for dates, reference IDs, and competency metrics.
- Bottom footer with a direct preview link or encrypted validation trigger.

### Metric Data Visualizations
- Custom score meters inspired by technical diagnostic reports: segmented horizontal progress bars with an electric cyan fill against a charcoal track (`#1E293B`).
- Tabular key-value blocks featuring low-contrast dividers (`rgba(255, 255, 255, 0.06)`) ensuring instant readability for research metrics and system benchmark outputs.
